# 토닥 · 어르신 앱 (On-Radar Android)

독거 어르신 돌봄 안전망 **토닥**의 어르신용 Android 앱입니다. 어르신은 하루 두 번 버튼 하나만 누르고, AI 말동무와 짧게 이야기합니다.

## 화면 흐름 (11/21 피드백 반영 기획)

```
등록(복지사가 설치·동의 안내) → 홈 [오늘 체크하기] → 몸 상태(아침) / 밥(저녁) → 짧은 대화 → 홈
모든 화면 하단 [도와주세요] → 복지사 즉시 알림(POST /emergency) → 119 다이얼 화면
```

- 한 화면에 질문 하나, 본문 26sp 이상, 버튼 72dp 이상
- 선택지는 글자 + 표정(이모지) + 색으로 표시
- 빨강은 [도와주세요]에만 사용
- 대화 중 "답변을 준비하고 있어요" / "듣고 있어요"를 글과 표시로 구분하고, 마이크를 못 쓰면 [다시 말하기] / [다음에 할게요]
- 인사·질문은 소리로도 읽어 줌 (TTS를 못 써도 버튼으로 진행 가능)
- 119 버튼은 긴급 화면 맨 위에 항상 있고, 복지사 알림 결과를 기다리지 않음 (다이얼만, 자동 통화 없음)

## 음성 인식이 안 될 때 (시연 폰 확인 사항)

앱은 Google 음성 인식 서비스가 있으면 그것을 직접 쓰고, 없으면 폰의 기본 음성 인식기를 씁니다. 삼성 폰은 기본값이 빅스비인데, 빅스비는 내부적으로 **Google 앱**의 음성 인식으로 넘깁니다. Google 앱이 꺼져 있으면 빅스비가 아무 응답도 주지 않으므로, 앱은 이를 미리 확인해 바로 "목소리 듣기가 꺼져 있어요"와 [다음에 할게요]를 보여 줍니다. (다른 이유로 응답이 없으면 5초 뒤 실패 안내)

시연 폰 준비물:
1. **Google 앱 켜기**: 설정 → 애플리케이션 → Google → 사용
2. **인터넷(Wi-Fi) 연결**: Google 음성 인식은 녹음을 Google 서버로 보내 글자로 바꿉니다. 연결이 없으면 "인터넷이 연결되지 않아 목소리를 들을 수 없어요"가 나옵니다.
3. **마이크 권한 허용**: 처음 [누르고 말씀하세요]를 누를 때 묻습니다.

Note 8(Android 9)에서 위 세 가지를 갖춘 뒤 한국어 음성이 글자로 바뀌는 것을 확인했습니다 (11/21).

개인정보 안내: 우리 서버(Core)에는 인식된 **글자만** 보냅니다. 다만 글자로 바꾸는 과정에서 녹음이 Google 음성 인식을 거치므로, 복지사가 동의를 받을 때 이 점도 함께 설명해야 합니다. 읽어 주기(TTS)는 폰 안의 Google TTS 음성으로 만들어집니다.

## 앱이 하지 않는 것

위험 점수·외로움·위기 판정, AI 답변·요약, 알림 단계 진행은 Core/AI 서비스 책임입니다. 앱은 서버가 준 상태(`status`, `opensAt`)와 문구만 보여 주고, 복지사 확인·출동 같은 상태나 알림 전송 성공을 지어내지 않습니다.

## 개발 환경

| 항목 | 값 |
|---|---|
| 시연 기기 | Galaxy Note 8 (Android 9, API 28) |
| minSdk / targetSdk / compileSdk | 28 / 36 / 37 |
| AGP / Gradle / Kotlin | 9.5.2 / 9.9.2 / 2.4.21 |
| UI | Jetpack Compose (BOM 2026.09.00), Navigation Compose |
| 통신 | Retrofit 3 + OkHttp 5 + kotlinx.serialization |
| 음성 | Android SpeechRecognizer(STT) + TextToSpeech |

SDK Manager에서 **Android 17 (API 37)** 플랫폼이 필요합니다. 폰은 minSdk 28 덕분에 Android 9에서 그대로 실행됩니다.

## 실행

Android Studio에서 폴더를 열고 ▶ 실행, 또는:

```
./gradlew installDebug
```

**debug 빌드는 시연 모드**(`USE_MOCK = true`)입니다. 백엔드 없이 앱 안의 가짜 데이터(API 명세서 JSON 예시)로 동작하고, 모든 화면 맨 위에 "시연 모드 · 실제로 전송되지 않아요"가 표시됩니다. 긴급 호출도 실제로 보내지 않았다고 안내합니다. **release 빌드는 항상 실서버**입니다.

실서버에 붙일 때:
1. `app/build.gradle.kts`의 `CORE_BASE_URL`을 배포 주소로 바꿉니다.
2. debug에서도 실서버를 쓰려면 `debug` 블록의 `USE_MOCK`을 `false`로 바꿉니다.
3. 시연 모드와 실서버 모드는 등록 정보를 따로 저장하므로, 실서버 모드에서는 등록 코드로 **다시 등록**해야 합니다. 서버가 토큰을 거부(401)하면 앱이 등록 화면으로 돌아가 복지사에게 재등록을 안내합니다.

## 구조

```
com.onradar.todak
├── core/
│   ├── designsystem/   # 색·글씨 크기, 큰 버튼, 하단 [도와주세요] 바
│   ├── network/        # Retrofit API 9개, X-Device-Token 헤더
│   ├── session/        # 기기 등록 토큰·이름 저장
│   └── speech/         # TTS(한국어 없으면 Google TTS로 대체), STT
├── data/
│   ├── model/          # API 명세서 (2) 기준 요청·응답 모델
│   └── repository/     # Remote / Fake 저장소
└── ui/
    ├── onboarding/     # 기기 등록 + 요약 전달 동의 안내
    ├── navigation/
    └── senior/         # home, check, chat, done, emergency
```
